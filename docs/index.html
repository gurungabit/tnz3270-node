Features

Full 3270 Protocol

Complete TN3270/TN3270E implementation — Write, Erase/Write, Read Buffer, Read Modified, WSF, and structured fields.

Zero Dependencies

Built entirely on Node.js built-ins (net, tls, events). No native modules, no bloat. Works with Node.js, Bun, and Deno.

ATI Automation Engine

High-level scripting API — send keystrokes, wait for screen conditions, extract data, and trigger conditional actions with the WHEN system.

IND$FILE Transfers

Native DDM IND$FILE protocol for uploading and downloading datasets and PDS members between your machine and the mainframe.

Concurrent Sessions

Event-driven socket architecture lets you run hundreds of mainframe sessions simultaneously without blocking the event loop.

Screen Scraping

Full EBCDIC/ASCII character-set awareness, field attribute parsing, color/highlight extraction, and password field cloaking.

Quick Start

import { Ati } from 'tnz3270-node'; const ati = new Ati(); // Connect to the mainframe await ati.connectSession('MVS', { host: '127.0.0.1', port: 3270, useTn3270e: true, }); // Wait for the logon screen await ati.wait(10, () => ati.scrhas('Logon ===>')); // Log in await ati.send('L HERC01[enter]'); await ati.wait(10, () => ati.scrhas('PASSWORD')); await ati.send('CUL8TR[enter]'); // Transfer a file await ati.getFile('sys1.proclib(test) ascii crlf', './local.txt'); ati.dropSession();
